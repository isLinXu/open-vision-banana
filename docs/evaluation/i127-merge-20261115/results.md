## 结论

- **六组融合都没有通过全部保护线。** 按预先约定的规则，均衡模型继续使用 **B·17.5k_best**。
- **ReasonSeg 是共同短板。** 六组 gIoU 为 37.12%–40.04%，保护线 42.35%，对照 43.10%，差距 3–6 pp，远大于重测噪声（约 0.2 pp）。
- **ETH3D 全部改善**，AbsRel 与 δ1 都优于对照。**Cityscapes** 在加入 B5k 或 W0 的三方配方中回升：P5 为 36.38%，P6 为 36.36%，均高于对照的 35.51%。
- 八项指标上，没有任何模型被另一模型全面支配，各方案只是取舍不同。偏深度可备选 **P2**（NYU 两项均优于对照，但 City 33.80%，且 DIODE 不稳定）或 **P6**（NYU δ1 +4.19 pp、City +0.85 pp，但 NYU AbsRel 变差）。

## 实现与口径

- **父模型**：I108 B 组 `_best` EMA adapter（r64 / α64 / rsLoRA），基座为 `Melo111/Fusion-C1-KQ0r128-60-40@9d5b9b8`。父 adapter 的 SHA-256 与 I108 归档一致，见 `provenance.json`。
- **融合**：精确的 ΔW 加权（`scripts/merge_lora_adapters.py`，`feat/lora-adapter-merge@bcdea62`）。把各父模型的 LoRA 因子拼接成 rank-128 adapter，使 ΔW = Σ wᵢ·8·BᵢAᵢ；FP32 计算，加载时 scale = 1。每个融合在 3 层上与父模型核对，最大误差约 4e-9。
- **自检**：M0 是 B17.5k 单独经过融合流程得到的模型。它在 NYUv2 前 100 张图上与 B17.5k 完全一致（AbsRel 0.26714 / δ1 48.98%，见 `evidence/calib/`）。
- **评测**：#120 外部评测套件，代码 `a8cc7e2`。bf16，512 画布，batch 1，50 步，guidance 4.0，seed 42，在原生 GT 尺寸上评分。ReasonSeg 为 query_v2 / 344 queries / legacy_union，RefCOCOg 为 UMD val 4896 条。
- **对照数据来源**：B17.5k 与 B5k 在本次重测；B20k 与 B100k 沿用 #120 的记录（代码与输入相同）。

## 观察与注意事项

1. **DIODE 稳定性。** P2、P3、P4 的 AbsRel 爆到 1.1–2.9，P1、P5、P6 保持在 0.50–0.75，与对照（0.51）接近。按约定，DIODE 不参与判定，只记录在此。
2. **保护线对噪声过于敏感。** 对照 B17.5k 自己重测 δ1 为 40.67%，比取自归档的阈值 40.69% 低 0.02 pp，结果对照本身也没通过 NYU 保护线；P1 同样只差 0.01 pp。两次评测之间，City 差 0.16 pp、Reason 差 0.25 pp。后续建议每个指标加约 0.3 pp 的容忍度，或改用同批重测的对照值作为基准。
3. **尚缺数据。** B5k 与 B20k 的 RefCOCOg 未评测，因此 P3、P4、P5 的 Ref 无法与父模型对比。
4. **数据泄漏风险。** 选比例时反复使用这几个外部评测集，它们已经变成开发信号；最终泛化结论需要独立的留出数据确认。

## 后续方向

`khazic/ovb-i127-merge-eval` 同时发布了 route T 的两份续训配置，用训练而不是合并来修复 2D 能力：

| 配置 | 起点 | 设置 |
| :-- | :-- | :-- |
| `i127_pushdepth` | B17.5k_best 的 EMA 权重 | 续训 10k 步，原 I108 混合比例，lr 1e-5 |
| `i127_repair2d` | B100k_final（online 权重） | 续训 12k 步，深度 15% / referring 25% / generation 20%，lr 5e-6 |

如果继续尝试合并，建议把 B100k 的占比降到 10–15%，或以 P5、P6 为基础细化，不再加大深度端的比例。
