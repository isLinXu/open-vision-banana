# Crablet 构建脚本

## macOS DMG 构建

### 前置依赖

- Rust 工具链（rustup + cargo）
- Node.js 22+（npm install）
- Tauri CLI（cargo install tauri-cli --version "^2"）

### 构建步骤

```bash
# 1. 安装前端依赖
cd frontend && npm install

# 2. 构建前端
cd .. && npm run build

# 3. 构建 Tauri 桌面端
cd desktop && ./build-desktop.sh --all
```

### DMG 输出

- 位置：`target/release/bundle/macos/Crablet.app`
- DMG：`target/release/bundle/dmg/Crablet_0.1.0_aarch64.dmg`

### 多平台 sidecar 编译与发布

在 CI（GitHub Actions）中：

1. 编译 `x86_64-apple-darwin` sidecar
2. 编译 `x86_64-pc-windows-msvc` sidecar
3. 编译 `x86_64-unknown-linux-gnu` sidecar
4. 发布到 GitHub Release Assets

## Windows EXE 构建

需在 Windows 环境或交叉编译。

## Linux AppImage / DEB 构建

需在 Linux 环境编译。

## 注意事项

- 编译前确保 `rustup target add` 所需目标
- macOS DMG 使用 `hdiutil`（系统自带）
- Windows EXE 需要在 Windows 环境或交叉编译
- Linux 包需在 Linux 环境编译
