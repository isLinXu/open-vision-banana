# Crablet 综合打包方案

## 目标

将前端项目打包为以下格式的安装包：
1. macOS DMG 安装包
2. Windows EXE 可执行文件
3. Linux AppImage / DEB 包
4. 可选的代码签名和公证

## 步骤

### 1. 编译 Rust 后端

```bash
cd /Users/gatilin/PycharmProjects/crablet-git
cargo build --release
```

### 2. 编译桌面端（Tauri sidecar）

```bash
cd desktop
cargo build --release
```

### 3. 生成图标资源

```bash
# 使用用户提供的 Logo PNG 生成全套图标
python3 scripts/generate-icons.py
```

### 4. 创建 DMG

```bash
# macOS
mkdir -p target/release/bundle/dmg
hdiutil create -volname "Crablet" -srcfolder target/release/bundle/macos/Crablet.app \
  -ov -format UDZO target/release/bundle/dmg/Crablet_0.1.0_aarch64.dmg
```

### 5. 创建 Windows EXE（需要在 Windows 环境或交叉编译）

```bash
# Linux
mkdir -p target/release/bundle/appimage
# ... 构建 AppImage ...
```

### 6. 创建 Linux DEB 包

```bash
# Linux
mkdir -p target/release/bundle/deb
# ... 构建 DEB ...
```

### 7. 代码签名（可选，需要 Apple Developer ID 证书）

```bash
# 代码签名
codesign --sign "Apple Development: gatilin@crablet.ai" \
  target/release/bundle/macos/Crablet.app

# 公证
xcrun notarytool submit target/release/bundle/dmg/Crablet_0.1.0_aarch64.dmg
```

### 8. 自动更新（Tauri updater 插件）

配置 Tauri 的 `updater` 插件，支持后台自动更新。

## 注意事项

- macOS DMG 使用 `hdiutil`（系统自带，无需安装额外工具）
- Windows EXE 需要在 Windows 环境编译或交叉编译
- Linux AppImage / DEB 需要在 Linux 环境编译
- 代码签名和公证需要 Apple Developer ID 证书
