# Crablet 后端打包优化方案

## 问题

当前后端打包存在以下问题：

1. **单一巨型二进制**：`cargo build --release` 生成单个大文件，包含所有依赖和功能。
2. **无 DMG/NSIS/AppImage 等安装包格式支持**。
3. **无代码签名**：缺少 Apple Developer ID 证书，macOS Gatekeeper 可能阻止运行。

## 优化策略

### 2.1 macOS DMG 打包

#### 方案 A：使用 `cargo-bundle`（推荐）

`cargo-bundle` 是 Rust 生态最成熟的打包工具，支持：

- macOS DMG（Apple Silicon + Intel）
- Windows NSIS 安装程序
- Linux AppImage / DEB

#### 方案 B：手动脚本

如果不想用 `cargo-bundle`，可以编写脚本：

1. 编译 Rust 后端 → `target/release/crablet`
2. 打包前端静态文件 → `target/release/frontend/`
3. 使用 `hdiutil` 创建 DMG（macOS 内置）
4. 可选：使用 `create-dmg`（更美观，但需额外安装）

### 2.2 Windows EXE 打包

在 Windows 上交叉编译：

```bash
rustup target add x86_64-pc-windows-msvc
cargo build --release --target x86_64-pc-windows-msvc
```

或在 Windows 上直接构建：

```powershell
# PowerShell
cd desktop
cargo build --release  # 自动编译 Rust + 前端
```

### 2.3 Linux 打包

```bash
rustup target add x86_64-unknown-linux-gnu
cargo build --release --target x86_64-unknown-linux-gnu
```

## 关键步骤

1. 编译后端：`cargo build --release`
2. 打包前端：复制 `frontend/dist/` 到 DMG
3. 创建 DMG：`hdiutil create` 或 `cargo-bundle`
4. 签名：`codesign`（需 Apple Developer ID）

## 注意事项

- macOS 上 `hdiutil` 是内置工具，无需额外安装
- `cargo-bundle` 需要安装：`cargo install cargo-bundle`
- `create-dmg` 是第三方工具，建议用 `hdiutil` 代替
