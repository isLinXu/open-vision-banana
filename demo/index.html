Where it breaks: right shape, wrong direction.

The trick: geometry, written in colour.

The model never outputs a number. It paints a colour, and a fixed rule turns that colour back into metres or a direction.

f(d) = 1 − (1 − d / λc)λ+1 with λ = −3 and c = 10/3, walked along the edges of the RGB cube. The map is one-to-one, so the model's colour decodes back to metres. The bar at the top of this page uses the same ramp for how far you have scrolled.

A direction is a colour

Hover the sphere

Camera frame: +x right, +y up, +z toward you. A surface facing you is always rgb(128, 128, 255), which is why normal maps look periwinkle. The same rule lights the scene at the top.

    What this page does not show

    • The pictures come from the earlier SANA-1600M adapter. The current Qwen-Image-2.1 runs publish numbers but no images yet (experiment E5).
    • The paper's absolute numbers are context, not a target: Nano Banana Pro and its in-house data are closed.
    • Metric depth is scored without scale alignment. ReasonSeg uses the original queries, so it is diagnostic.
    • Generation preservation is a pixel and perceptual proxy, not the paper's human study.
